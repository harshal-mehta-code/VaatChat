# Audio recording checklist

Native-speaker recordings to replace the TTS placeholders. Each row maps to the
exact file the app already expects — **drop the recorded `.mp3` at that path**
under `public/` and it plays automatically (no code change).

**Recording tips:** clear, natural, unhurried pace · standard Gujarati · quiet
room · one phrase per file · normalize levels · MP3 (or WAV, then convert).
Where a phrase has a blank (…), record it as a natural pause.

> ⚠️ Please also **verify the Gujarati script + romanization + English** in each
> row while recording — this content is an AI-drafted first pass awaiting your
> review. Note any corrections and I'll update the content files.

## Akshar Lab — letters (`public/audio/akshar/…`)

**Vowels:** `a, aa, i, ii, u, uu, e, ai, o, au` → e.g. `/audio/akshar/aa.mp3` = આ.
**Consonants:** `ka, kha, ga, cha, ja, ta-retro (ટ), da-retro (ડ), ta (ત), da (દ), na, pa, ba, ma, ra, la, va, sa, ha`.
Record each letter in isolation (its standalone sound). Optionally record barakshari
combinations later; the app can synthesize those for now.
